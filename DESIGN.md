# Spatial portfolio

A visual, interactive workspace replaces the previous studio direction. The opening combines a CSS 3D laptop, a modeled keyboard and platform, floating development/design/AI tiles, and a violet palette. Pointer movement changes the perspective; three labeled buttons rotate and reset the scene for keyboard and touch users. Reduced-motion preferences disable pointer movement and transitions. The scene is decorative and does not obscure portfolio content.

Projects use a responsive gallery with original perspective illustrations: a browser, phone, and layered cards. These are labeled as illustrations; real project images take precedence. About and skills use rounded grids, and contact has a dedicated panel. Light and dark themes are available. The new theme preference uses its own storage key so a saved preference from the rejected studio design does not prevent the new default from appearing.

The scene uses native CSS transforms and React; no WebGL runtime, 3D engine, external model, or additional dependency is required. Manrope and IBM Plex Mono are self-hosted with their OFL licenses. The implementation preserves the optional Supabase connection, preview labeling, real data loading, contact fallback, and authentication/admin workflows.

All scene and cover artwork is implemented specifically for this portfolio. The previous research repositories informed earlier iterations, not this composition; no third-party portfolio artwork or layout code was copied.
