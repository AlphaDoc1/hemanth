# Portrait-led portfolio

The hero pairs the saved profile image with the introduction. The portrait replaces the former decorative 3D laptop and its controls. Desktop uses two balanced columns; tablets and phones stack the content and image. The portrait uses containment to preserve the full image. If neither profile nor hero image is configured, the introduction uses a single column without an empty image panel.

Projects retain the perspective illustration gallery, technology filters, violet palette, rounded panels, and light/dark themes. Saved project images take precedence over decorative illustrations. Manrope and IBM Plex Mono are self-hosted with their OFL licenses.

The optional Supabase connection, preview labeling, saved content loading, contact fallback, and authentication/admin workflows remain supported.
